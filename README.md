# 人事管理系統(類 FemasHR)

純靜態前端(GitHub Pages)+ Google Apps Script 後端 + Google 試算表資料庫。

## 功能

| 模組 | 說明 |
| --- | --- |
| 員工資料 | 管理員新增 / 編輯 / 離職、重設密碼,指定直屬主管;**Excel 批次匯入**(含範本下載、整批驗證、自動產生初始密碼) |
| 請假與簽核 | 假別餘額檢查、申請、撤回;主管簽核直屬部屬的假單 |
| 打卡與出勤 | 上班 / 下班打卡、每日紀錄、主管月報表 |
| GPS 定點打卡 | 管理員設定多個打卡地點與允許半徑,**輸入名稱或地址自動搜尋座標**(Google 地圖,失敗時改用 OpenStreetMap),後端以 Haversine 公式驗證距離 |
| 排班管理 | 班別設定、主管以月曆格式批次排班,員工檢視自己班表 |

角色:`admin`(人資管理員)、`manager`(主管,管理 `主管員編` 指向自己的員工)、`employee`。

## 目錄

```
index.html / style.css / app.js / api.js / config.js   前端
vendor/xlsx.mini.min.js                                SheetJS 0.18.5(Excel 讀寫,僅在使用匯入時載入)
apps-script/Code.gs, appsscript.json                   後端(貼到 Apps Script)
```

## 先試用(示範模式)

`config.js` 的 `API_URL` 留空時,系統使用瀏覽器內建示範資料,不連線任何服務。
示範帳號:`A001 / admin1234`(管理員)、`M001 / demo1234`(主管)、`E001 / demo1234`(員工)。

## 部署

### 1. 建立後端

1. 新增一份 Google 試算表。
2. 選單「擴充功能 → Apps Script」,把 `apps-script/Code.gs` 的內容貼進去;
   「專案設定」勾選「顯示 appsscript.json」,貼入 `apps-script/appsscript.json`。
3. 在編輯器執行函式 **`setup`**(第一次會要求授權)。會建立 7 個工作表與預設資料:
   管理員 `A001`,密碼 `admin1234`。
4. 「部署 → 新增部署作業 → 網頁應用程式」:執行身分選「我」,存取權選「任何人」。
5. 複製「網頁應用程式網址」(`https://script.google.com/macros/s/.../exec`)。

> 之後修改 `Code.gs` 需「部署 → 管理部署作業 → 編輯 → 新版本」才會生效。

### 2. 設定前端

把網址貼進 `config.js` 的 `API_URL`,commit 並 push。

### 3. 啟用 GitHub Pages

Repo → Settings → Pages → Source 選 `Deploy from a branch`,Branch 選 `main` / `(root)`。
約一分鐘後可在 `https://<帳號>.github.io/hr-system/` 使用。

### 4. 首次設定

1. 用 `A001 / admin1234` 登入,立刻到「修改密碼」。
2. 「打卡地點」:新增公司地點(可在現場按「使用目前位置」),設定允許半徑。
3. 「員工資料」:新增員工並指定主管。
4. 「假別」「班別」可直接在試算表對應工作表修改。

## Excel 批次匯入員工

員工資料頁按「下載 Excel 範本」,依欄位填寫後按「Excel 批次匯入」。

- 整批先驗證,**有任何錯誤就一筆都不寫入**,並列出每一列的問題。
- 員編已存在者更新資料(密碼欄留空不會改密碼),其餘新增。
- 新員工「初始密碼」留空時自動產生隨機密碼,匯入完成後顯示並可下載清單(只顯示一次)。
- 單次最多 500 筆;支援 .xlsx / .xls / .csv,日期可寫 `2025-03-01` 或 `2025/3/1`。

## 新增打卡地點

「打卡地點 → 新增地點」輸入名稱(或在地址欄輸入更精確的地址)按「搜尋座標」。只有一個結果會自動帶入,多個結果請選擇;
儲存前請點「在地圖上確認位置」。名稱太籠統(例如只寫「門市」)可能搜不到,請改填完整地址。

## 資料表

`員工`、`假別`、`請假`、`打卡`、`地點`、`排班`、`班別`(欄位由 `setup()` 建立)。

## 安全說明

- 密碼以加鹽 SHA-256 存放,登入 token 存在 Apps Script 快取,6 小時過期;連續錯誤 5 次鎖定 15 分鐘。
- 所有權限檢查都在後端,前端隱藏選單只是方便使用。
- **GPS 為瀏覽器回報的座標,技術上可被偽造(例如模擬定位 App)**。本系統能擋住一般誤打與遠端代打,
  若需要更嚴格的防弊,需搭配原生 App 或其他驗證方式。
- 員工個資只存在你的 Google 試算表,不在這個 repo 中。
- `vendor/xlsx.mini.min.js` 為 SheetJS 0.18.5;該版本有已知的「讀取惡意構造檔案」弱點(prototype pollution),所以請只匯入自己製作或可信來源的 Excel 檔,且僅管理員可使用匯入功能。請勿把試算表公開分享。
- Apps Script 「任何人」存取指的是任何人都能呼叫 API,但沒有登入 token 就拿不到資料。
